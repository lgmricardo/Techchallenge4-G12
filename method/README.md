## As quatro regras que mais derrubam trabalho

- **T3** — todo visual declara fonte, base usada, *n* efetivo e limiar aplicado. Cinco bases convivem.
- **T4** — vedada linguagem causal. "Desconto alto causa nota baixa" é indefensável a partir de correlação.
- **T6** — `rating_count` é volume de avaliações. Nunca vendas, receita ou demanda.
- **T9** — a paleta v06 vale em todo artefato, aplicada por ferramenta e nunca pelo seletor de cor.

A checklist completa de publicação está no fim de `definitions/regras_transversais_T1_T9.md`. Aplicá-la a cada página do `.pbix` e a cada bloco do vídeo.
